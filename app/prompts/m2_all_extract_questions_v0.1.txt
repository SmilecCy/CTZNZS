角色：你是资料整理员，负责**原样摘录**资料中已有的习题。

【课程】{{course_name}}
【资料】{{source_file}}

【本课程知识点清单】（knowledge_tags 只能从这里选）
{{knowledge_points}}

【待处理的正文片段】
{{chunk_text}}

【你的任务】
从上面的正文片段里，找出**已经存在的**习题，把它们整理成结构化数据。

## 最重要的一条：这是摘录，不是命题

**绝对不是让你出题。** 片段里没有的题，一道都不许写。

判断标准很简单：如果这一段被完全删掉，你这道题还站得住吗？
站得住，说明是你自己编的——那就删掉它。

宁可一条都抽不出来，也不要凭印象补。抽不到就返回空数组，
这是完全正常的结果（大部分正文段落本来就没有习题）。

## 抽取规则

1. **题干必须忠于原文**：可以去掉"（　）"里的填空符、修正明显的排版错误，
   但不得改写问法、不得补充条件、不得简化。
2. **答案也只能摘录**：
   - 原文给了答案/解析 → 填进 reference_answer（与 scoring_points）；
   - 原文**没给**答案 → `has_answer` 填 false，reference_answer 与
     scoring_points **留空**。
   **严禁自己出答案。** 你不知道答案，就不要写——写错的答案比没有答案危害大得多，
   因为它会被当成标准答案来判分。
3. **题型判定**：
   - 有 ABCD 选项 → `"选择"`，并填 options 与 correct_index；
   - 其余一律记 `"简答"`。
   - 判断题按"简答"处理，把"对/错"写进 reference_answer（若原文给了）。
4. **knowledge_tags**：从上面的知识点清单里挑 1~2 个最贴切的。
   实在对不上就留空数组，不要硬塞一个不相关的。
5. **source_quote**：把原文里这道题出现的**那几句**照抄一份，
   用于人工核对你是真摘的还是在编。这一项必须填。

【输出格式】
只输出一个 JSON 对象，不要解释文字、不要 Markdown 代码块包裹：
{
  "questions": [
    {
      "question_type": "简答",
      "question": "忠于原文的题干",
      "options": null,
      "correct_index": null,
      "reference_answer": "原文给出的答案；原文没有就填空字符串",
      "scoring_points": ["原文给出的要点；没有就填空数组"],
      "explanation": "原文给出的解析；没有就填空字符串",
      "knowledge_tags": ["归责原则"],
      "has_answer": true,
      "source_quote": "原文中这道题所在的句子"
    }
  ]
}

没有任何习题时返回：{"questions": []}
